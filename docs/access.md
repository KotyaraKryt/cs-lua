# Права доступа

Право — именованная нода: `admin.kick`, `shop.vip.buy`. Плагин заводит столько
нод, сколько ему нужно.

```lua
if p:can("shop.vip.buy") then ... end

command("slay", function(ctx)
	ctx.target:slay()
end, { perm = "admin.slay", target = 1 })   -- !slay kotyarakryt
```

**У консоли и rcon прав нет — им всё можно.** `ctx.player` там `nil`, любая
проверка проходит: у кого консоль сервера, у того и так всё.

## API

| вызов | что делает |
|-------|------------|
| `p:can(node)` | есть ли право |
| `p:group(name)` | состоит ли в группе (с наследованием) |
| `p:groups()` | список групп |
| `p:weight()` | иммунитет |
| `p:outranks(other)` | старше ли другого |
| `permission { node, desc =, default = }` | объявить ноду |
| `access.rule(node, fn)` | динамическое правило |
| `access.grant(key, spec)` | выдать: `{ groups=, allow=, deny=, until_=, where= }` |
| `access.revoke(key[, группа][, нода])` | забрать запись, группу или ноду |
| `access.save()` | записать `users.lua` (атомарно, с `.bak`) |
| `access.reload()` | перечитать оба файла без `lua_reload` |
| `access.invalidate([p])` | сбросить кеш прав |
| `access.config` | тексты отказов, `warn_unknown` |

Выдача из кода видна сразу; в файл она попадает только по `access.save()`.

## Файлы

`data/groups.lua` — правится руками, модуль его только читает:

```lua
return {
	default   = { weight = 0,   allow = { "chat.say" } },
	vip       = { weight = 10,  inherit = "default", allow = { "shop.vip.*" } },
	moderator = { weight = 30,  inherit = "vip", allow = { "admin.kick" } },
	admin     = { weight = 50,  inherit = "moderator", allow = { "admin.*" },
	              deny = { "admin.rcon" } },
	owner     = { weight = 100, inherit = "admin", allow = { "*" } },
}
```

`data/users.lua` — кто есть кто. Ключ: steamid или `name:<ник>`.

```lua
return {
	["STEAM_0:1:12345"] = { name = "kotyarakryt", groups = { "owner" } },
	["STEAM_0:0:99999"] = { groups = { "vip" }, until_ = 1785000000 },
	["name:Helper"]     = { password = "secret", groups = { "moderator" },
	                        where = { map = "de_dust2" } },
}
```

| поле | значение |
|------|----------|
| `until_` | unix-время, `"30d"`/`"12h"` при выдаче из кода, `"map"` до конца карты |
| `where` | `{ map = "de_dust2" }` или `{ maps = {...} }`; есть и у групп |
| `password` | сверяется с `setinfo _pw` на клиенте |

Оба файла необязательны: без `groups.lua` работают встроенные `default`,
`admin`, `owner`. Битый файл — понятная ошибка в консоль и пустая половина, а не
половинчатые права. Файлы выполняются в пустом окружении: это данные, а не код,
ни `io`, ни `os` внутри не видно.

> **Вход по нику годится только для LAN.** Ник подделывается тривиально, а
> пароль летит по сети открытым текстом. На публичном сервере права выдавай
> только по steamid.

## Кто выигрывает

Нода в выдаче может быть с хвостовой звёздочкой (`shop.vip.*`, `*`) и с минусом
впереди (`-admin.ban` — явный запрет). Права берутся и из групп, и из личных
записей одновременно.

Кто побеждает — решает не порядок в файле, а сравнение по четырём признакам:

1. **источник** — личная запись > своя группа > унаследованная > `default` ноды;
2. **вес** — среди групп одного уровня выигрывает более тяжёлая;
3. **точность** — `shop.vip.buy` > `shop.vip.*` > `shop.*` > `*`;
4. **запрет** — при полном равенстве выигрывает `deny`.

Поэтому `admin` с `allow = {"admin.*"}` и `deny = {"admin.rcon"}` получает всё
кроме rcon, а личный `allow = {"admin.rcon"}` в записи игрока это перебивает.

## Иммунитет

`weight` группы. Действие против другого игрока требует **строго большего**
веса, поэтому два админа одного ранга друг друга не тронут.

Руками — `p:outranks(other)`, декларативно — `opts.target` в `command()`:
роутер сам найдёт игрока, положит в `ctx.target` и откажет, если у цели
иммунитет выше. Отключается через `immunity = false`.

## Объявление нод и динамические правила

```lua
permission { "shop.vip.buy", desc = "Покупка в VIP-магазине", default = "vip" }
```

Необязательно, но полезно: нода попадёт в `lua_perms list` с описанием, а
опечатка в `p:can("shop.vip.by")` даст предупреждение в консоль вместо тихого
«нельзя». `default` раздаёт ноду группе (или всем через `true`) с самым низким
приоритетом — любой `deny` в файлах забирает её обратно.

Если правами должна управлять логика, а не таблица:

```lua
access.rule("shop.buy", function(p, ctx)
	return p:playtime() > 3600
end)
```

Правило спрашивают **только когда ноду не покрыл никто**. Явный `deny` в файлах
всегда сильнее — иначе запреты нельзя было бы гарантировать.

## Из консоли

```
lua_perms who 3
lua_perms check 3 admin.kick
lua_perms grant STEAM_0:1:12345 vip 30d
lua_perms revoke STEAM_0:1:12345 vip
lua_perms save
```

Права считаются лениво и кешируются на слот. Кеш сбрасывается сам: на
`player_authorized`, на смене карты, по истечении срока и при любом изменении.
