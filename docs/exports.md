# Межплагинное общение

Плагины изолированы: глобалки одного не видны другому. Общаются через два
механизма, они отвечают на разные вопросы.

| функция | что делает |
|---------|------------|
| `export(name, fn [, opts])` | опубликовать; `opts.version`, `opts.override` |
| `import(plugin)` | прокси; ошибка, если плагина нет |
| `optional(plugin)` | прокси или `nil` |
| `emit(event, ...)` | разослать событие |
| `on_export(event, id, fn)` | подписаться |
| `plugin_id()` | id текущего плагина (`nil` в core) |

Кто что опубликовал и кто на что подписан — консольная команда `exports_debug`.

## export / import

«Вызови то, что умеет вон тот плагин».

```lua
-- в плагине admin_manager
export("open", function(p) ui.root(p) end)

-- в любом другом
local admin = import("admin_manager")     -- ошибка, если плагина нет
local shop  = optional("shop")            -- nil, если плагина нет

admin.open(p)
if shop then shop.give(p, "vip") end
```

`import` — жёсткая зависимость: падаем сразу при загрузке, а не через час на
`nil`-вызове. `optional` — мягкая, возвращает `nil`.

**Плагины грузятся по алфавиту**, поэтому `import()` на этапе загрузки видит
только тех, кто отсортирован раньше. Если порядок неудобен — бери зависимость
лениво, внутри обработчика, или через `optional`.

Прокси резолвит функцию на каждом вызове, поэтому после `lua_reload` в руках не
останется указателя на код исчезнувшего плагина. Ошибка внутри самого экспорта
не роняет вызывающего — заворачивается в `[export плагин.имя] ...`.

## emit / on_export

«Сообщи всем, кому интересно».

```lua
emit("admin.rights_changed", target, "give", actor)

on_export("admin.rights_changed", "Bans.Sync", function(target, what, actor)
	-- ...
end)
```

Второй аргумент `on_export` — id слушателя. Он делает подписку идемпотентной:
повторная загрузка плагина заменит своего слушателя, а не повесит второго.
Ошибка в слушателе логируется и не мешает остальным.
