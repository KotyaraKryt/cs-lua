# Команды

Один `command()` покрывает и чат (`!name` / `/name`), и серверную консоль/rcon.

```lua
command("heal", function(ctx)
	local p = ctx.player            -- nil, если из консоли/rcon
	local n = tonumber(ctx.args[1]) or 25
	if p then p:health(p:health() + n) end
	ctx.reply("healed +" .. n)      -- ответ туда, откуда пришла команда
end)
```

| поле `ctx` | что это |
|------------|---------|
| `ctx.player` | игрок, вызвавший из чата; `nil` для консоли/rcon |
| `ctx.args` | массив аргументов (слова после имени) |
| `ctx.name` | имя команды |
| `ctx.source` | `"console"`, `"chat"` или `"chat_team"` |
| `ctx.reply(text)` | ответить туда, откуда пришло |
| `ctx.target` | игрок из аргумента, если задан `opts.target` |
| `ctx.can(node)` | проверить право вызвавшего |

## opts

| поле | значение |
|------|----------|
| `source` | где слушать: `"console"`, `"chat"`, `"chat_team"`, список или ничего (везде) |
| `perm` | нода, проверяется до запуска хендлера |
| `target` | номер аргумента, называющего игрока → `ctx.target` |
| `immunity` | `false` отключает проверку иммунитета при `target` |

```lua
command("kick",  fn, { source = "console" })                -- только rcon/консоль
command("plant", fn, { source = "chat_team" })              -- только командный чат
command("menu",  fn, { source = { "chat", "chat_team" } })  -- любой чат
command("heal",  fn)                                        -- везде

command("slay", fn, { perm = "admin.slay", target = 1 })    -- !slay kotyarakryt
```

Распознанная чат-команда проглатывается и в общий чат не попадает.

**Команды вечны на стороне движка.** `lua_reload` меняет только Lua-обработчик,
имя в движке остаётся. Если после перезагрузки плагин команду не переобъявил —
она становится пустышкой.

Для сырого текста чата (антифлуд, логи, свой синтаксис) есть событие
`player_chat`.

## Команды самого модуля

| команда | что делает |
|---------|------------|
| `lua_reload` | пересоздаёт Lua-стейт и перечитывает все плагины |
| `lua_list` | список плагинов, счётчики хендлеров и таймеров |
| `lua_precache` | сколько слотов прекеша занято и сколько осталось |
| `lua_perms <что>` | `groups`, `list`, `users`, `who`, `check`, `grant`, `revoke`, `save`, `reload` |
| `exports_debug` | кто что публикует и кто на что подписан |

### Диагностика

Пишут **всем, кто сейчас на сервере**, — запускать на пустом.

| команда | что делает |
|---------|------------|
| `lua_chat <текст>` | шлёт всем в чат, теги цвета работают |
| `lua_chat_as <id> <текст>` | то же от имени игрока — видно, как красит `{team}` |
| `lua_hud <текст>`, `lua_dhud <текст>` | то же в HUD и DHUD |
| `lua_test_ru` | «Привет» в UTF-8 и в CP1251 — какой вариант читается |
| `lua_debug` | id user messages, кеш игроков, 4 пробные строки в чат |

`lua_debug` отвечает на вопрос «сообщение вообще уходит или нет»: печатает id
`SayText` и `TextMsg`, состояние кеша игроков и шлёт одну строку четырьмя
разными способами. Если не видно ни одной пробы, а кеш заполнен — дело не в
отправке, а в том, что игрок ещё не в игре.
