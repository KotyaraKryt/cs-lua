# Вывод: чат, HUD, меню

| метод | куда |
|-------|------|
| `p:chat(text[, opts])` | в чат, с тегами цвета |
| `p:console(text)` | в консоль игрока |
| `p:center(text)` | по центру экрана |
| `p:hud(text[, opts])` | HUD с позицией, цветом и таймингами |
| `p:dhud(text[, opts])` | directed HUD (`SVC_DIRECTOR`) |

`all:chat(...)` шлёт всем подключённым.

## Цветной чат

Три тега:

| тег | что даёт |
|-----|----------|
| `{default}`, `{yellow}` | обычный жёлто-белый |
| `{green}` | зелёный |
| `{team}` | цвет команды: синий за CT, красный за T, серый у зрителя |

```lua
p:chat("{green}[Server]{default} Привет, {team}" .. p:name() .. "{default}!")
```

Цвет `{team}` считается по «отправителю» сообщения. По умолчанию отправитель —
сам получатель, поэтому каждый видит `{team}` в цвете своей команды. Поменять:

```lua
all:chat("{team}" .. p:name() .. "{default} слил бомбу", { from = p })
```

Синий и красный по своему выбору получить нельзя — только через живого игрока из
нужной команды.

## HUD

Второй аргумент — таблица, любое поле можно опустить.

```lua
p:hud("Round started", {
	x = -1, y = 0.3,        -- -1 = по центру оси
	color = { 0, 255, 0 },  -- {r, g, b} или {r, g, b, a}
	color2 = { 255, 0, 0 }, -- вторая точка градиента для effect = 2
	effect = 0,             -- 0 fade, 1 flicker, 2 typewriter
	fadein = 0.1, fadeout = 0.2,
	hold = 5, fxtime = 0.25,
	channel = 3,            -- 0..3, разные каналы не затирают друг друга
})
```

Дефолты: `x = -1`, `y = 0.35`, белый, `hold = 5`, `channel = 3`.

`channel` и `color2` относятся только к `hud`. DHUD показывает до 128 символов и
держит до 8 сообщений одновременно.

## Меню

```lua
local m = menu("Выбери оружие")

m:add("AK-47", function(p) p:give("weapon_ak47") end)
m:add("AWP",   function(p) p:give("weapon_awp") end)
m:add("Пока недоступно", nil, { disabled = true })   -- видно, нажать нельзя

m.on_exit = function(p) p:chat("закрыл меню") end
m:show(p)
```

| метод / поле | что делает |
|--------------|------------|
| `menu(title[, opts])` | создать; `opts.exit`, `opts.time`, `opts.on_exit`, `opts.color` |
| `m:add(text[, fn][, opts])` | пункт; `opts.disabled`, `opts.value`, `opts.color` |
| `m:show(p[, page])` | показать игроку |
| `m:close(p)` | убрать с экрана |
| `m:count()` | сколько пунктов |
| `m:color(spec)` | перекрасить меню целиком |
| `m:item_color(item, spec)` | перекрасить один пункт |

До 8 пунктов на странице, дальше разбивается само: `9` вперёд, `0` назад, на
первой странице `0` — выход (отключается через `{ exit = false }`).

Хендлер получает `(player, item)`, где `item` — то, что вернул `add()`, так что
на нём можно держать свои поля.

Ответ игрока перехватывается до игры, поэтому нажатая клавиша не улетит в меню
покупки. Устаревший ответ и клавиша, которой в меню не было, игнорируются.

### Цвета

Четыре цвета: `white`, `red`, `yellow`, `grey`. Пишутся именем или сырым кодом
(`"\r"`, как в AmxModX).

```lua
local m = menu("Оружие", { color = { title = "yellow", number = "red" } })

m:add("AWP",    fn, { color = "red" })                       -- весь текст пункта
m:add("Deagle", fn, { color = { number = "grey", text = "yellow" } })

m:color { number = "yellow" }        -- поменять на лету, до show()
m:item_color(m.items[1], "grey")
```

| ключ | что красит |
|------|------------|
| `title` | заголовок |
| `number` | номера пунктов |
| `text` | текст пунктов |
| `nav` | номера `Next`/`Back`/`Exit` (по умолчанию как `number`) |
| `disabled` | пункт целиком, если `disabled = true` (по умолчанию `grey`) |

Код цвета действует до следующего кода и переносится через строки. Поэтому
рендер ставит их только там, где цвет реально меняется: меню без `color` уходит
на клиент байт в байт таким же, а серый `disabled`-пункт не красит всё под ним.

## Кириллица

`.lua` обычно лежат в UTF-8, и современный клиент CS 1.6 так их и рисует —
**по умолчанию модуль ничего не конвертирует и шлёт строку как есть.**

Старые клиенты ждут однобайтовый CP1251 и показывают UTF-8 мусором. Для них есть
переключатель:

```
cslua_cp1251 1
```

С ним валидный многобайтовый UTF-8 переводится в CP1251, а строка, которая
UTF-8 не является (уже сохранённая в CP1251, чистый ASCII), уходит нетронутой.
Символы, которых в CP1251 нет, заменяются на `?`.

Конвертация касается только сообщений игрокам, включая текст меню: панель
кодируется целиком до нарезки на пакеты, поэтому символ не рвётся пополам.
`print` пишет в лог сервера как есть, всегда.

### Длина строки

Каждый канал заканчивается фиксированным буфером и обрезает молча. `#s` при этом
врёт: тег `{green}` занимает 7 байт в Lua и 1 на проводе, а кириллическая буква
— 2 и 1 соответственно.

Считать по-настоящему умеет `include/text.lua`:

```lua
local text = require("text")

text.width(s)          --> сколько байт реально уйдёт
text.fits(s, "chat")   --> влезет ли
text.clip(s, "chat")   --> обрезать, не разорвав символ или тег
```

| канал | лимит, байт |
|-------|------------|
| `chat` | 188 |
| `dhud` | 127 |
| `hud` | 511 |
| `center`, `console` | 254 |
