# p:origin

Позиция игрока в мире.

```lua
p:origin([x, y, z])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | новые координаты; без них метод читает |

## Возвращает

| тип |  |
|---|---|
| `number, number, number` | три компоненты вектора |

> [!NOTE]
> Запись телепортирует: проверки столкновений нет, игрока можно
> засунуть в стену.
