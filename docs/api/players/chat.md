# p:chat

Отправляет строку в чат.

```lua
p:chat(text[, opts])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `text` | string | текст; понимает теги цвета |
| 2 | `opts` | table \| nil | см. [Опции](#опции) |

## Возвращает

Ничего.

## Опции

| поле | тип |  |
|---|---|---|
| `from` | player | чей цвет команды подставит `{team}` |

## Пример

```lua
p:chat("{green}[Server]{default} Привет, {team}" .. p:name())
```

Теги цвета — в [`ui`](../ui/color.md). Лимит строки — 188 байт.
