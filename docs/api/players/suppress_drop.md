# p:suppress_drop

Блокирует команду `drop` до того, как её увидит игра.

```lua
p:suppress_drop([bool])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `bool` | boolean \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `boolean` | включена ли блокировка сейчас |

## Пример

```lua
p:suppress_drop(true)
-- ...
p:suppress_drop(false)
```

Перехватывает клиентскую команду `drop` в `ClientCommand` — обработчик игры
до неё не доходит вообще, оружие никогда не становится отдельной сущностью в
мире. Это единственный надёжный момент для блокировки: брошенное оружие
уносит с собой собственный патронник, и достать его оттуда через игрока
после броска уже нечем.

Не забывай выключать: включённая блокировка переживает то, ради чего её
поставили, если явно не снять.
