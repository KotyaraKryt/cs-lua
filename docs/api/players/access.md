# Права

Добавлены core-слоем, подробности — в [`access`](../access/index.md).

## p:can {#can}

Есть ли у игрока право.

```lua
p:can(node)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `node` | string | нода вида `admin.kick` |

### Возвращает

| тип |  |
|---|---|
| `boolean` | есть ли у игрока право |

### Пример

```lua
if p:can("shop.vip.buy") then ... end
```

## p:groups {#groups}

Массив групп игрока.

```lua
p:groups()
```

### Возвращает

| тип |  |
|---|---|
| `table` | массив групп игрока |

## p:group {#group}

Состоит ли игрок в группе, с учётом наследования.

```lua
p:group(name)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя группы |

### Возвращает

| тип |  |
|---|---|
| `boolean` | состоит ли игрок в группе, с учётом наследования |

### Возвращает

| тип |  |
|---|---|
| `number` | вес игрока для иммунитета |

## p:outranks {#outranks}

Старше ли игрок другого по весу.

```lua
p:outranks(other)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `other` | player | кого сравниваем |

### Возвращает

| тип |  |
|---|---|
| `boolean` | старше ли игрок другого по весу |

Требует **строго большего** веса, поэтому два админа одного ранга друг друга не тронут.
