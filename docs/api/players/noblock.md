# p:noblock

Проходят ли сквозь игрока другие игроки.

```lua
p:noblock([bool])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `bool` | boolean \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если игрок сейчас проходим для других |

## Пример

```lua
p:noblock(true)
timer.after(1.5, function()
	if p:connected() then p:noblock(false) end
end)
```

Меняет `SOLID_NOT`/`SOLID_SLIDEBOX` — это влияет только на то, как **другие**
сущности обходят этого игрока при трассировке. На собственное движение
игрока против уровня не влияет: `PM_Move` клипует против мира напрямую, не
через это поле. В отличие от [`p:noclip`](noclip.md) сквозь стены не
проваливает.

Полезно на секунду-две после телепорта/респауна в место, где уже кто-то
стоит — иначе игрока раздвигает в сторону вместо честного оверлапа.
