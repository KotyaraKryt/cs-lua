# p:ammo

Читает или задаёт патроны в запасе.

```lua
p:ammo([weapon][, value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `weapon` | string \| nil | classname; без него — оружие в руках |
| 2 | `value` | number \| nil | новое количество |

## Возвращает

| тип |  |
|---|---|
| `number` | патронов в запасе |

## Пример

```lua
p:ammo()                     -- запас для оружия в руках
p:ammo("weapon_ak47", 90)
```

Запас ключуется оружием, а не типом патрона: оружие одного калибра делит запас. Запись ограничена потолком игры.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
