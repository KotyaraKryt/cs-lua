# CS-состояние

Читает и меняет `CBasePlayer` игры.

## p:team {#team}

Читает или меняет сторону игрока.

```lua
p:team([team[, opts]])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `team` | string \| nil | `CT`, `T`, `SPEC`; без него метод читает |
| 2 | `opts` | table \| nil | см. [Опции](#team-опции) |

### Возвращает

| тип |  |
|---|---|
| `string` | `CT`, `T`, `SPEC` или `NONE` |

### Опции {#team-опции}

| поле | тип |  |
|---|---|---|
| `force` | boolean | игрок умирает и заходит заново, как это делает игра |

### Пример

```lua
p:team("CT")                      -- сторона меняется, игрок остаётся жив
p:team("T", { force = true })     -- через смерть и повторный вход
```

Вход из спектатора всегда идёт как force: мягкий путь не умеет завести зрителя в идущий раунд.

<Warning>
Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
</Warning>

### Смотри также

- [p:spawn](cs-state.md#spawn)

## p:spawn {#spawn}

Респаун игрока без потери денег и счёта.

```lua
p:spawn()
```

### Возвращает

Ничего.

Тот же `RoundRespawn`, что игра делает между раундами. Работает и на живом, и на мёртвом. У игрока в `SPEC` или `NONE` не делает ничего.

<Warning>
Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
</Warning>

<Note>
`p:team(t, { force = true })` — не респаун: он убивает живого
игрока, экран мигает, счёт сбрасывается.
</Note>

## p:money {#money}


### Аргументы

| # | имя | тип |  |
|---|---|---|---|

## p:ammo {#ammo}

Читает или задаёт патроны в запасе.

```lua
p:ammo([weapon][, value])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `weapon` | string \| nil | classname; без него — оружие в руках |
| 2 | `value` | number \| nil | новое количество |

### Возвращает

| тип |  |
|---|---|
| `number` | патронов в запасе |

### Пример

```lua
p:ammo()                     -- запас для оружия в руках
p:ammo("weapon_ak47", 90)
```

Запас ключуется оружием, а не типом патрона: оружие одного калибра делит запас. Запись ограничена потолком игры.

<Warning>
Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
</Warning>
