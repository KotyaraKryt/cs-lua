# Сообщения

Те же методы есть у [`players.broadcast`](namespace.md#broadcast).

## p:chat {#chat}

Отправляет строку в чат.

```lua
p:chat(text[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `text` | string | текст; понимает теги цвета |
| 2 | `opts` | table \| nil | см. [Опции](#chat-опции) |

### Возвращает

Ничего.

### Опции {#chat-опции}

| поле | тип |  |
|---|---|---|
| `from` | player | чей цвет команды подставит `{team}` |

### Пример

```lua
p:chat("{green}[Server]{default} Привет, {team}" .. p:name())
```

Теги цвета — в [`ui`](../ui/index.md#color). Лимит строки — 188 байт.

## p:hud {#hud}

Рисует текст на HUD с позицией, цветом и таймингами.

```lua
p:hud(text[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `text` | string | до 511 байт |
| 2 | `opts` | table \| nil | см. [Опции](#hud-опции) |

### Возвращает

Ничего.

### Опции {#hud-опции}

| поле | тип |  |
|---|---|---|
| `x, y` | number | позиция 0..1; `-1` — по центру оси. По умолчанию `-1`, `0.35` |
| `color` | string \| table | имя, `"#rrggbb"` или `{ r, g, b[, a] }` |
| `color2` | string \| table | вторая точка градиента для `effect = 2` |
| `effect` | number | `0` fade, `1` flicker, `2` typewriter |
| `fadein` | number | по умолчанию `0.1` |
| `fadeout` | number | по умолчанию `0.2` |
| `hold` | number | секунд на экране, по умолчанию `5` |
| `fxtime` | number | по умолчанию `0.25` |
| `channel` | number | `0..3`, разные каналы не затирают друг друга |

### Пример

```lua
p:hud("Раунд начался", { y = 0.3, color = "green", hold = 3 })
```

## p:screen_fade {#screen_fade}

Заливает экран игрока цветом с угасанием.

```lua
p:screen_fade([opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `opts` | table \| nil | см. [Опции](#screen_fade-опции) |

### Возвращает

Ничего.

### Опции {#screen_fade-опции}

| поле | тип |  |
|---|---|---|
| `color` | string \| table | имя, `"#rrggbb"` или `{ r, g, b[, a] }`; по умолчанию чёрный |
| `alpha` | number | `0..255`, по умолчанию `200`; перекрывает 4-й компонент `color` |
| `duration` | number | секунд на угасание, по умолчанию `1.0` |
| `hold` | number | секунд держать перед угасанием, по умолчанию `0` |
| `out` | boolean | `true` — экран чистый и заливается цветом; по умолчанию `false` — экран залит и очищается |
| `modulate` | boolean | смешивать вместо сплошной заливки |
| `stay` | boolean | держать залитым до следующего `screen_fade`, игнорируя `duration` |

### Пример

```lua
-- вспышка урона
p:screen_fade({ color = "red", alpha = 120, duration = 0.5 })

-- затемнение на весь экран, которое держится, пока не снимут
p:screen_fade({ color = "black", alpha = 255, out = true, stay = true })
```

## p:motd {#motd}

Открывает игроку панель MOTD.

```lua
p:motd(text[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `text` | string | до 1536 байт после обёртки |
| 2 | `opts` | table \| nil | см. [Опции](#motd-опции) |

### Возвращает

Ничего.

### Опции {#motd-опции}

| поле | тип |  |
|---|---|---|
| `raw` | boolean | слать как есть, разметку пишет плагин |

### Пример

```lua
p:motd(table.concat(lines, "\n"))

p:motd([[<meta charset="utf-8">
<body style="background:#111;color:#ddd">
  <h3>Магазин</h3>
  <table><tr><td>AK-47</td><td>2500</td></tr></table>
</body>]], { raw = true })
```

Единственная многострочная поверхность в игре: меню — это девять клавиш, а HUD —
одна строка. Каталог магазина, топ-10 и правила сервера показывают здесь.

### Панель — это HTML

У клиентов, которые ещё запускают, MOTD рисует HTML-вьюха, а не текстовое поле.
Из этого следуют две вещи, знать которые вызывающему незачем, поэтому по
умолчанию модуль разбирается с ними сам:

| | |
|---|---|
| перевод строки | в HTML это пробел, поэтому `\n` заменяется на `<br>` |
| кодировка | без объявления движок читает UTF-8 как системную кодовую страницу и показывает мусор, поэтому в начало идёт `<meta charset>` |
| `<`, `>`, `&` | экранируются: ник с угловой скобкой не должен становиться разметкой |
| шрифт | моноширинный — в панели показывают таблицы цен и топы, пропорциональный их разъезжает |

`raw = true` отключает всю обёртку: текст уходит байт в байт, `<meta charset>`
пишешь сам. Это режим для оформления — фон, цвета, таблицы.

Текст уходит кусками по 60 байт, клиент собирает их обратно; снаружи это один
вызов.

<Note>
Заголовок самого окна задаёт клиент: в протоколе поля для него
нет.
</Note>

<Warning>
Длиннее 1536 байт обрезается, и считается это уже вместе с
обёрткой. При `cslua_cp1251 1` кириллица занимает вдвое меньше,
чем в UTF-8.
</Warning>

## p:play_sound {#play_sound}

Проигрывает игроку звук.

```lua
p:play_sound(path[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `path` | string | путь от `cstrike/sound/`, обязан быть предкэширован |
| 2 | `opts` | table \| nil | см. [Опции](#play_sound-опции) |

### Возвращает

Ничего.

### Опции {#play_sound-опции}

| поле | тип |  |
|---|---|---|
| `volume` | number | 0..1, по умолчанию `1.0` |
| `attenuation` | number | затухание с расстоянием; `0` — одинаково слышно везде. По умолчанию `0.8` |
| `channel` | number | канал звука, по умолчанию `0` |
| `pitch` | number | тон, по умолчанию `100` |

### Пример

```lua
p:play_sound("items/9mmclip1.wav", { attenuation = 0 })
```

Это `EMIT_SOUND`, движковый вызов уровня всего сервера: он эмитится из этого игрока как из точки в мире, и слышит его любой, чей PAS накрывает эту точку — не обязательно только `p`. `attenuation = 0` не делает звук приватным, только одинаково громким всем, кто его услышал. Для звука, который должен услышать ровно этот игрок и никто больше, используй [`p:exec`](admin.md#exec) с консольной командой `spk`: `p:exec('spk "путь/без/точки/wav"')` — это настоящая адресная команда клиенту, а не излучение в мир.
