# p:motd

Открывает игроку панель MOTD с текстом.

```lua
p:motd(text)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `text` | string | до 1536 байт после перекодировки |

## Возвращает

Ничего.

## Пример

```lua
p:motd(table.concat(lines, "\n"))
```

Единственная многострочная поверхность в игре: меню — это девять клавиш, а HUD —
одна строка. Каталог магазина, топ-10 и правила сервера показывают здесь.

Текст уходит кусками по 60 байт, клиент собирает их обратно — это делает модуль,
снаружи видно один вызов.

> [!NOTE]
> Заголовок окна задаёт клиент, а не сервер: в протоколе его нет.

> [!WARNING]
> Длиннее 1536 байт обрезается. Считать надо после перекодировки:
> в CP1251 кириллица занимает вдвое меньше, чем в UTF-8.
