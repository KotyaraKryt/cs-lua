# p:trace_to

Пускает луч из глаз игрока прямо к другому игроку.

```lua
p:trace_to(other)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `other` | player | до кого трассировать |

## Возвращает

| тип |  |
|---|---|
| `table` | что попалось, см. [Результат](trace.md#результат) — тот же формат, что у `p:trace` |

## Пример

```lua
local t = p:trace_to(victim)
if t.kind == "player" and t.player.id == victim.id then
	-- прямая видимость есть, между ними ничего твёрдого
end
```

`p:trace()` отвечает «куда сейчас смотрит `p`»; этот — «есть ли что-то твёрдое между `p` и `other`». Разница важна там, где важна не текущая наводка, а сам факт видимости: разброс дроби или отдача уводят прицел в сторону от точки, куда реально попала пуля, так что трассировка по прицелу в момент попадания может соврать — трассировка прямо на цель нет.
