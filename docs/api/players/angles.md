# p:angles

Поворот модели игрока.

```lua
p:angles([x, y, z])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | новые координаты; без них метод читает |

## Возвращает

| тип |  |
|---|---|
| `number, number, number` | три компоненты вектора |
