# p:maxspeed

Максимальная скорость движения.

```lua
p:maxspeed([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | новое значение; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение при чтении; при записи ничего |
