# p:kick

Отключает игрока от сервера.

```lua
p:kick([reason])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `reason` | string \| nil | показывается игроку в консоли перед отключением |

## Возвращает

Ничего.

Идёт через консольную команду движка и адресуется по userid: ник может содержать пробелы и кавычки.
