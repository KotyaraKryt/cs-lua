# p:money

Читает или задаёт деньги игрока.

```lua
p:money([amount[, opts]])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `amount` | number \| nil | новая сумма; без неё метод читает |
| 2 | `opts` | table \| nil | см. [Опции](#опции) |

## Возвращает

| тип |  |
|---|---|
| `number` | текущая сумма при чтении |

## Опции

| поле | тип |  |
|---|---|---|
| `hud` | boolean | мигнуть цифрой на экране, как при подборе денег |

## Пример

```lua
p:money(p:money() + 1000, { hud = true })
```

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
