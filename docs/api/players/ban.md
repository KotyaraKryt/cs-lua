# p:ban

Банит игрока.

```lua
p:ban(minutes[, reason])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `minutes` | number | срок в минутах; `0` — навсегда |
| 2 | `reason` | string \| nil | показывается игроку |

## Возвращает

Ничего.

Бан ложится в тот же список, которым управляет админ сервера, и сохраняется через `writeid`.
