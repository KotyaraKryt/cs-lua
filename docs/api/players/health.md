# p:health

Здоровье игрока.

```lua
p:health([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | новое значение; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение при чтении; при записи ничего |

## Пример

```lua
p:health(p:health() + 25)
```

> [!WARNING]
> Обращение к состоянию отключённого игрока бросает ошибку.
> В таймерах и отложенных коллбэках проверяй `p:connected()`.
