# p:progress_bar

Показывает нативный прогресс-бар под прицелом — тот же, что игра рисует при
установке/разминировании бомбы.

```lua
p:progress_bar(seconds)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `seconds` | number | длительность; `0` убирает бар досрочно |

## Возвращает

Ничего.

## Пример

```lua
p:progress_bar(3)
-- клиент сам отсчитывает три секунды и гасит бар; чтобы прервать раньше:
p:progress_bar(0)
```

Разовая команда, не значение для чтения: клиент считает сам, обновлять
каждый кадр не нужно. Идёт через `SetProgressBarTime` (`ICSPlayer`,
`CSPlayer.h`) — требует ReGameDLL.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
