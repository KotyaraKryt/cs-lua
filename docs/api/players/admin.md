# Админские действия

## p:kick {#kick}

Отключает игрока от сервера.

```lua
p:kick([reason])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `reason` | string \| nil | показывается игроку в консоли перед отключением |

### Возвращает

Ничего.

Идёт через консольную команду движка и адресуется по userid: ник может содержать пробелы и кавычки.

## p:ban {#ban}

Банит игрока.

```lua
p:ban(minutes[, reason])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `minutes` | number | срок в минутах; `0` — навсегда |
| 2 | `reason` | string \| nil | показывается игроку |

### Возвращает

Ничего.

Бан ложится в тот же список, которым управляет админ сервера, и сохраняется через `writeid`.

## p:slay {#slay}

Убивает игрока.

```lua
p:slay()
```

### Возвращает

Ничего.

Через `TakeDamage` от мира, поэтому отрабатывает всё как при обычной смерти: дроп оружия, сообщение, проверка конца раунда.

## p:slap {#slap}

Наносит урон и толкает игрока в случайную сторону.

```lua
p:slap([damage])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `damage` | number \| nil | по умолчанию `1`; `0` — только толчок |

### Возвращает

Ничего.

## p:exec {#exec}

Выполняет консольную команду на машине игрока.

```lua
p:exec(command)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `command` | string | до 120 символов |

### Возвращает

Ничего.
