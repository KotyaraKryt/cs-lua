# p:group

Состоит ли игрок в группе, с учётом наследования.

```lua
p:group(name)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя группы |

## Возвращает

| тип |  |
|---|---|
| `boolean` | состоит ли игрок в группе, с учётом наследования |
