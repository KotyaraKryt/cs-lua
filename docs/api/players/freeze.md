# p:freeze

Заморозка движения (`FL_FROZEN`).

```lua
p:freeze([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | boolean \| nil | новое значение; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `boolean` | текущее значение при чтении; при записи ничего |

Движковая заморозка. Обычный обходной путь `p:maxspeed(1)` оставляет клиент предсказывать движение, которого сервер не даёт — отсюда рывки.
