# p:weapons

Массив classname всего, что несёт игрок.

```lua
p:weapons()
```

## Возвращает

| тип |  |
|---|---|
| `table` | массив classname всего, что несёт игрок |

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
