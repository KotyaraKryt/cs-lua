# Состояние

Пишется в `entvars_t` напрямую, ReGameDLL не нужен.

## p:health {#health}

Здоровье игрока.

```lua
p:health([value])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | новое значение; без него метод читает |

### Возвращает

| тип |  |
|---|---|
| `number` | текущее значение при чтении; при записи ничего |

### Пример

```lua
p:health(p:health() + 25)
```

<Warning>
Обращение к состоянию отключённого игрока бросает ошибку.
В таймерах и отложенных коллбэках проверяй `p:connected()`.
</Warning>

## p:trace {#trace}

Пускает луч из глаз игрока туда, куда он смотрит.

```lua
p:trace([distance])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `distance` | number \| nil | длина луча в юнитах, по умолчанию `8192` |

### Возвращает

| тип |  |
|---|---|
| `table` | что попалось, см. [Результат](#trace-результат) |

### Результат {#trace-результат}

| поле | тип |  |
|---|---|---|
| `kind` | string | `player`, `entity`, `world`, `none` |
| `player` | player | только при `kind == "player"` |
| `classname` | string | classname цели; нет при `none` |
| `x, y, z` | number | точка попадания; при `none` — конец луча |
| `distance` | number | юнитов от глаз до точки |
| `hitgroup` | number | `1` — голова, `0` — тело |

### Пример

```lua
local t = p:trace()
if t.kind == "player" then
	p:chat(("%s, %d hp, %d юнитов"):format(t.player:name(), t.player:health(), t.distance))
end
```

## p:trace_to {#trace_to}

Пускает луч из глаз игрока прямо к другому игроку.

```lua
p:trace_to(other)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `other` | player | до кого трассировать |

### Возвращает

| тип |  |
|---|---|
| `table` | что попалось, см. [Результат](state.md#trace-результат) — тот же формат, что у `p:trace` |

### Пример

```lua
local t = p:trace_to(victim)
if t.kind == "player" and t.player.id == victim.id then
	-- прямая видимость есть, между ними ничего твёрдого
end
```

`p:trace()` отвечает «куда сейчас смотрит `p`»; этот — «есть ли что-то твёрдое между `p` и `other`». Разница важна там, где важна не текущая наводка, а сам факт видимости: разброс дроби или отдача уводят прицел в сторону от точки, куда реально попала пуля, так что трассировка по прицелу в момент попадания может соврать — трассировка прямо на цель нет.
