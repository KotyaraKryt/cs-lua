# p:suppress_attack

Блокирует выстрел до того, как его увидит оружие.

```lua
p:suppress_attack([bool])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `bool` | boolean \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `boolean` | включена ли блокировка сейчас |

## Пример

```lua
p:suppress_attack(true)
-- ...
p:suppress_attack(false)
```

Каждый кадр перед тем, как код оружия увидит нажатые кнопки, снимает
`IN_ATTACK`/`IN_ATTACK2` из состояния игрока. Выстрела не происходит вообще —
ни вспышки, ни звука, ни расхода патрона — в отличие от попытки погасить
последствия постфактум (`weapon_fire` приходит уже после выстрела, отменить
его нечем).

Не забывай выключать: включённая блокировка переживает то, ради чего её
поставили, если явно не снять.
