# p:spawn

Респаун игрока без потери денег и счёта.

```lua
p:spawn()
```

## Возвращает

Ничего.

Тот же `RoundRespawn`, что игра делает между раундами. Работает и на живом, и на мёртвом. У игрока в `SPEC` или `NONE` не делает ничего.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.

> [!NOTE]
> `p:team(t, { force = true })` — не респаун: он убивает живого
> игрока, экран мигает, счёт сбрасывается.
