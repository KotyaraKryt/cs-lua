# p:suppress_move

Блокирует WASD до того, как их увидит движение.

```lua
p:suppress_move([bool])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `bool` | boolean \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `boolean` | включена ли блокировка сейчас |

## Пример

```lua
p:suppress_move(true)
-- ...
p:suppress_move(false)
```

Каждый кадр снимает `IN_FORWARD`/`IN_BACK`/`IN_MOVELEFT`/`IN_MOVERIGHT` из
состояния игрока, тем же способом, что [`p:suppress_attack`](suppress_attack.md)
снимает кнопки стрельбы. Прыжок и повороты мышью не трогает — только ход.

Не [`p:freeze`](freeze.md): `FL_FROZEN` тянет за собой `pev->button` целиком,
включая кнопки, которые сама механика читает каждый тик, чтобы понять, держат
ли её ещё — с ним «удержание кнопки» само себя отменяло и тут же
перезапускало на каждом тике таймера.

Не забывай выключать: включённая блокировка переживает то, ради чего её
поставили, если явно не снять.
