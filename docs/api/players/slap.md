# p:slap

Наносит урон и толкает игрока в случайную сторону.

```lua
p:slap([damage])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `damage` | number \| nil | по умолчанию `1`; `0` — только толчок |

## Возвращает

Ничего.
