# p:clip

Читает или задаёт патроны в магазине.

```lua
p:clip([weapon][, value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `weapon` | string \| nil | classname; без него — оружие в руках |
| 2 | `value` | number \| nil | новое количество |

## Возвращает

| тип |  |
|---|---|
| `number \| nil` | `nil` у ножа и гранат — магазина у них нет |

Цифра доходит до HUD только для оружия в руках; при переключении она встаёт правильная.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
