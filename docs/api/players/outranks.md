# p:outranks

Старше ли игрок другого по весу.

```lua
p:outranks(other)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `other` | player | кого сравниваем |

## Возвращает

| тип |  |
|---|---|
| `boolean` | старше ли игрок другого по весу |

Требует **строго большего** веса, поэтому два админа одного ранга друг друга не тронут.
