# p:info

Читает ключ инфобуфера клиента.

```lua
p:info(key)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `key` | string | имя ключа, например `_pw` |

## Возвращает

| тип |  |
|---|---|
| `string` | читает ключ инфобуфера клиента |

## Пример

```lua
local password = p:info("_pw")
```
