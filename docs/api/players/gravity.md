# p:gravity

Множитель гравитации.

```lua
p:gravity([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | новое значение; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение при чтении; при записи ничего |

`1.0` — обычная, `0.5` — вдвое слабее.

> [!NOTE]
> Спавн сбрасывает значение. Ставь его в
> [`player_spawn`](../hook/player_spawn.md), снимай в
> [`plugin.on_unload`](../plugin/on_unload.md).
