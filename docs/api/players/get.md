# players.get

Возвращает игрока по номеру слота.

```lua
players.get(id)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `id` | number | номер слота, 1..32 |

## Возвращает

| тип |  |
|---|---|
| `player \| nil` | `nil`, если слот пуст |
