# p:drop

Выбрасывает оружие на пол.

```lua
p:drop([weapon])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `weapon` | string \| nil | classname; без него — то, что в руках |

## Возвращает

Ничего.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
