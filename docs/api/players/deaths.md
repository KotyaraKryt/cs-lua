# p:deaths

Счётчик смертей.

```lua
p:deaths([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | новое значение; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение при чтении; при записи ничего |

Запись обновляет строку в таблице счёта.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
