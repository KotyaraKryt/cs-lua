# p:strip

Забирает у игрока всё оружие.

```lua
p:strip([suit])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `suit` | boolean \| nil | `true` — вместе с бронежилетом |

## Возвращает

Ничего.

> [!WARNING]
> Требует ReGameDLL. На ванильном `mp.dll` метод бросает ошибку.
