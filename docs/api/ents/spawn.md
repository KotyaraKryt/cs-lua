# e:spawn

Запускает `Spawn` сущности.

```lua
e:spawn()
```

## Возвращает

Ничего.

Именно это превращает голый edict в объект с хитбоксом и think-функцией. Вызывать после того, как выставлены модель и позиция.

> [!WARNING]
> Объект от удалённой сущности — или переживший `changelevel` —
> бросает `entity #N is gone`. Проверяй [`e:valid()`](valid.md).
