# Пространство имён

## ents.create {#create}

Создаёт сущность по classname.

```lua
ents.create(classname)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `classname` | string | `info_target`, `func_door`, … |

### Возвращает

| тип |  |
|---|---|
| `entity \| nil` | новая сущность |
| `string` | причина, если игра не знает classname |

### Пример

```lua
hook.add("round_start", "drops.spawn", function()
	local e = ents.create("info_target")
	e:model("models/w_ak47.mdl")
	e:origin(x, y, z)
	e:spawn()
end)
```

Возвращает голый edict: игра ещё не превратила его ни во что. Сначала модель и
позиция, потом [`e:spawn()`](entity.md#spawn) — `Spawn` читает уже выставленные поля. В
обратном порядке получится сущность, которую игра игнорирует.

Модель обязана быть предкэширована через [`res.model`](../res/index.md#model), а это
делается в теле плагина.

<Warning>
Пока карта не загружена, сущностей не существует. Тело плагина
выполняется задолго до неё, и здесь это ошибка. Создавай сущности
из события: `round_start`, `player_spawn`, таймер, команда.
</Warning>

## ents.find {#find}

Находит все сущности с заданным classname.

```lua
ents.find(classname)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `classname` | string | что искать |

### Возвращает

| тип |  |
|---|---|
| `table` | массив сущностей, пустой если ничего нет |

## ents.in_sphere {#in_sphere}

Находит все сущности в радиусе от точки.

```lua
ents.in_sphere(x, y, z, radius)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | центр |
| 2 | `radius` | number | радиус в юнитах |

### Возвращает

| тип |  |
|---|---|
| `table` | массив сущностей, порядок произвольный |

Из этого делается зона: объём без собственной сущности-триггера.

<Warning>
Пока карта не загружена, сущностей не существует. Тело плагина
выполняется задолго до неё, и здесь это ошибка. Создавай сущности
из события: `round_start`, `player_spawn`, таймер, команда.
</Warning>
