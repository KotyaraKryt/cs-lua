# Пространство имён

## ents.create {#create}

Создаёт сущность по classname.

```lua
ents.create(classname)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `classname` | string | `info_target`, `func_door`, … |

### Возвращает

| тип |  |
|---|---|
| `entity \| nil` | новая сущность |
| `string` | причина, если игра не знает classname |

### Пример

```lua
hook.add("round:start", "drops.spawn", function()
	local e = ents.create("info_target")
	e:model("models/w_ak47.mdl")
	e:origin(x, y, z)
	e:spawn()
end)
```

Возвращает голый edict: игра ещё не превратила его ни во что. Сначала модель и
позиция, потом [`e:spawn()`](entity.md#spawn) — `Spawn` читает уже выставленные поля. В
обратном порядке получится сущность, которую игра игнорирует.

Модель обязана быть предкэширована через [`res.model`](../res/index.md#model), а это
делается в теле плагина.

<Warning>
Пока карта не загружена, сущностей не существует. Тело плагина
выполняется задолго до неё, и здесь это ошибка. Создавай сущности

## ents.trace_line {#trace_line}

Пускает луч между двумя произвольными точками.

```lua
ents.trace_line(a, b[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `a` | table | точка старта, `{x, y, z}` |
| 2 | `b` | table | точка конца, `{x, y, z}` |
| 3 | `opts` | table \| nil | см. Опции ниже |

### Возвращает

| тип |  |
|---|---|
| `table` | что попалось — тот же формат, что у [p:trace](../players/state.md#trace-результат) |

### Опции {#trace_line-опции}

| поле | тип |  |
|---|---|---|
| `skip` | entity \| player \| nil | луч эту сущность игнорирует |
| `ignore_monsters` | boolean | `true` — луч летит сквозь монстров/ботов |

### Пример

```lua
local a = { 0, 0, 0 }
local b = { 100, 0, 0 }
local t = ents.trace_line(a, b)
if t.kind ~= "none" then
	print(t.classname, t.distance)
end
```

В отличие от [`p:trace`](../players/state.md#trace) — который стреляет из
глаз игрока — здесь оба конца луча произвольные: ничьи глаза не нужны.
Годится для эффектов, самодельных снарядов, проверки прямой видимости между
двумя сущностями.

## ents.trace_hull {#trace_hull}

То же самое, что `ents.trace_line`, но толкает объём, а не бесконечно тонкий луч.

```lua
ents.trace_hull(a, b[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `a` | table | точка старта, `{x, y, z}` |
| 2 | `b` | table | точка конца, `{x, y, z}` |
| 3 | `opts` | table \| nil | опции `ents.trace_line`, плюс `hull` |

### Возвращает

| тип |  |
|---|---|
| `table` | что попалось — тот же формат, что у [p:trace](../players/state.md#trace-результат) |

### Опция hull {#trace_hull-опция hull}

| поле | тип |  |
|---|---|---|
| `0` | number | точка — то же самое, что `trace_line` |
| `1` | number | стоящий игрок (по умолчанию) |
| `2` | number | крупный объём |
| `3` | number | голова, для приседа |

### Пример

```lua
local t = ents.trace_hull({ 0, 0, 0 }, { 0, 0, -100 }, { hull = 1 })
```

Тем же движковым вызовом (`TRACE_HULL`) пользуется `sv.hull_free` — только
там объём нулевой длины и результат сведён к да/нет; здесь — полный трейс
вдоль пути.
