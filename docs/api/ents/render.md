# e:render

Читает или задаёт прозрачность и свечение.

```lua
e:render([opts])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `opts` | table \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `table` | `{ mode =, amount =, color =, fx = }` |

## Опции

| поле | тип |  |
|---|---|---|
| `mode` | number | `0` обычно, `2` прозрачность по amount, `5` аддитивно |
| `amount` | number | `0..255`, насколько видно |
| `color` | table | `{ r, g, b }` |
| `fx` | number | эффект: пульсация, мерцание |

## Пример

```lua
e:render({ mode = 2, amount = 128, color = { 255, 0, 0 } })
```

Таблица опций, а не пять чисел подряд: который из них renderfx, никто не помнит.
