# e:body

Читает или задаёт под-модель studio-модели.

```lua
e:body([n])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

Косметика, на физику и хитбокс не влияет. У моделей игроков переключает
такие вещи, как кобура на бедре.
