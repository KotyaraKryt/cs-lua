# e:skin

Читает или задаёт группу текстур studio-модели.

```lua
e:skin([n])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

У моделей игроков — вариант камуфляжа/команды, зашитый в саму модель.
Косметика, на физику не влияет.
