# e:movetype

Читает или задаёт, как движок двигает сущность.

```lua
e:movetype([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

## Частые значения

| поле | тип |  |
|---|---|---|
| `0` | number | не двигается |
| `4` | number | летит, гравитации нет |
| `5` | number | падает и лежит — дроп предмета |
| `6` | number | толкает, как дверь |
| `8` | number | отскакивает, как граната |
| `10` | number | следует за другой сущностью |
