# e:movetype

Читает или задаёт, как движок двигает сущность.

```lua
e:movetype([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

## Частые значения

Значения из `cssdk/common/const.h` (`MOVETYPE_*`) — раньше здесь стоял
неверный набор, в частности follow был указан как `10` вместо `12`.

| поле | тип |  |
|---|---|---|
| `0` | number | не двигается |
| `4` | number | гравитация, для монстров |
| `5` | number | летит, гравитации нет |
| `6` | number | падает и лежит — дроп предмета |
| `7` | number | толкает, как дверь |
| `8` | number | летит без гравитации и коллизий |
| `10` | number | отскакивает, как граната |
| `12` | number | следует за другой сущностью — см. [`e:attach`](attach.md) |

> [!NOTE]
> Для follow не выставляй `12` вручную — [`e:attach`](attach.md) делает это
> вместе с `aiment` и оффсетом, чего одним `movetype` не добиться.
