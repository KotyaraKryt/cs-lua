# e:origin

Читает или задаёт позицию сущности.

```lua
e:origin([x, y, z])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | новая позиция; без них метод читает |

## Возвращает

| тип |  |
|---|---|
| `number, number, number` | координаты |

Запись идёт через движок и перелинковывает сущность в мире; присваивание `pev->origin` напрямую оставило бы её сталкиваться там, где она была.

> [!WARNING]
> Объект от удалённой сущности — или переживший `changelevel` —
> бросает `entity #N is gone`. Проверяй [`e:valid()`](valid.md).
