# e:angles

Читает или задаёт поворот сущности.

```lua
e:angles([x, y, z])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | новые углы; без них метод читает |

## Возвращает

| тип |  |
|---|---|
| `number, number, number` | углы |

> [!WARNING]
> Объект от удалённой сущности — или переживший `changelevel` —
> бросает `entity #N is gone`. Проверяй [`e:valid()`](valid.md).
