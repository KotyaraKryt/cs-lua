# ents.hide_corpses

Глушит нативный рэгдолл трупа у всех игроков.

```lua
ents.hide_corpses(bool)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `bool` | boolean | `true` — прятать, `false` — вернуть как было |

## Возвращает

Ничего.

## Пример

```lua
hook.add("player_death", "myplugin.hide", function(e)
	ents.hide_corpses(true)
end)

hook.add("player_spawn", "myplugin.show", function(e)
	ents.hide_corpses(false)
end)
```

Глобальный рубильник, не «спрячь труп вот этого игрока»: сообщение `ClCorpse`
не несёт ничего, по чему можно понять, чей это труп — это сообщение
ReGameDLL/CS, для него нет заголовка в SDK, только рантайм-имя. Пока включено
хотя бы одно `true` без парного `false`, прячутся рэгдоллы **всех** смертей,
не только той, ради которой звали.

Счётчик, а не флаг: `hide_corpses(true)` можно звать несколько раз подряд (по
одному на труп, который сейчас отслеживается) — рэгдоллы вернутся только
когда число `false` сравняется с числом `true`. Каждый вызов держи в паре:
включил при создании трупа — выключи, когда труп разрешился, любым путём
(подняли, истёк, игрок вышел).

Трупа как сущности нет вообще — рэгдолл это чисто клиентский рендер по
одному сообщению, отправленному один раз при смерти. Спрятать существующий
нечем, только запретить сообщению уйти заранее.
