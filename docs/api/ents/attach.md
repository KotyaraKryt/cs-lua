# e:attach

Прикрепляет сущность к игроку — движком, без ручного `origin`/`angles` в
таймере каждый кадр.

```lua
e:attach(player[, x, y, z])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `player` | player | к кому прицепить |
| 2 | `x, y, z` | number \| nil | смещение от игрока; без них — `0, 0, 0` |

## Возвращает

Ничего.

Ставит `e:movetype(12)` (`MOVETYPE_FOLLOW`) и `aiment` на edict игрока.
Дальше движок сам, каждый серверный кадр, кладёт сущность в
`player:origin() + offset` и копирует на неё углы игрока целиком — pitch,
yaw и roll. Тикер и ручной `e:origin()`/`e:angles()` не нужны.

> [!NOTE]
> Смещение хранится в поле `v_angle` — оно не используется никем, кроме
> игрока (там это угол обзора), так что сущность его свободно занимает.
> Отдельно задать угол сущности нельзя: пока она прикреплена, её `angles`
> движок каждый кадр перезаписывает углами `player`.

## Пример

```lua
local hat = ents.create("info_target")
hat:model("models/caps/ushanka.mdl")
hat:solid(0)
hat:spawn()
hat:attach(p, 0, 0, 40)   -- сидит на 40 юнитов выше игрока
```
