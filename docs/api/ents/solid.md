# e:solid

Читает или задаёт тип столкновений.

```lua
e:solid([value])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | number \| nil | без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

## Значения

| поле | тип |  |
|---|---|---|
| `0` | number | не сталкивается ни с чем |
| `1` | number | триггер: срабатывает на касание, но не мешает |
| `2` | number | ограничивающий параллелепипед |
| `3` | number | skid box, как у игрока |
| `4` | number | brush-модель из карты |

> [!NOTE]
> `e:spawn()` может выставить своё значение: у многих classname
> Spawn задаёт solid сам. Ставь после спавна, если важно.
