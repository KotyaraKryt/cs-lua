# e:model

Читает или задаёт модель сущности.

```lua
e:model([path])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `path` | string \| nil | путь к модели; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `string` | текущая модель |

> [!WARNING]
> Модель обязана быть предкэширована через
> [`res.model`](../res/model.md). Не предкэшированная стоит серверу
> ошибки, а сущность рисуется ничем.

> [!WARNING]
> Объект от удалённой сущности — или переживший `changelevel` —
> бросает `entity #N is gone`. Проверяй [`e:valid()`](valid.md).
