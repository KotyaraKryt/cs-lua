# e:frame

Читает или задаёт позицию внутри анимации.

```lua
e:frame([n])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| nil | `0..255`; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

`0..255` — это нормализованная позиция внутри текущей последовательности, а
не номер реального кадра: GoldSrc передаёт её по сети байтом, одинаково для
любой длины анимации. `255` вместе с [`e:framerate(0)`](framerate.md) —
классический трюк «застыть на последней позе», им же пользовался
оригинальный AMXX-плагин для трупов (`set_entvar(iEnt, var_frame, 255.0)`).
