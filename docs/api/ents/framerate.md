# e:framerate

Читает или задаёт скорость анимации.

```lua
e:framerate([n])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| nil | `1.0` — обычная скорость; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущее значение |

`0` останавливает анимацию ровно там, где её оставил [`e:frame`](frame.md),
вместо того чтобы проигрывать её дальше от этой точки.
