# e:sequence

Читает или задаёт номер анимации studio-модели.

```lua
e:sequence([n])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| nil | номер последовательности; без него метод читает |

## Возвращает

| тип |  |
|---|---|
| `number` | текущий номер |

Только по номеру: движок не даёт найти последовательность по имени
(`LookupSequence` — метод `CBaseAnimating`, который сам разбирает `.mdl`, а не
вызов движка) — искать `death1`/`death2`/… приходится перебором номеров и
наблюдением, что проигрывается.
