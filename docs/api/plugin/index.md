# plugin

Манифест, пути плагина и его выгрузка.

`plugin` — одновременно вызов манифеста и пространство имён.

|  |  |
|---|---|
| [`plugin{}`](plugin.md) | Объявляет метаданные и требования плагина |
| [`plugin.id`](id.md) | Имя папки плагина или файла без `.lua` |
| [`plugin.dir`](dir.md) | Абсолютный путь к папке плагина |
| [`plugin.data_dir`](data_dir.md) | Каталог плагина под данные, переживающий обновление |
| [`plugin.on_unload`](on_unload.md) | Регистрирует обработчик выгрузки этого плагина |
