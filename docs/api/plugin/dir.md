# plugin.dir

Абсолютный путь к папке плагина.

```lua
plugin.dir()
```

## Возвращает

| тип |  |
|---|---|
| `string \| nil` | `nil` у одиночного `.lua` |

> [!WARNING]
> Здесь лежит код, и установщик перезаписывает его при обновлении.
> Данные клади в [`plugin.data_dir()`](data_dir.md).
