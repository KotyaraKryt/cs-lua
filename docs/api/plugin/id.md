# plugin.id

Имя папки плагина или файла без `.lua`.

```lua
plugin.id()
```

## Возвращает

| тип |  |
|---|---|
| `string \| nil` | `nil` в core-слое |

Это и есть идентичность плагина: у одиночного `.lua` она тоже есть, в отличие от `plugin.dir()`.
