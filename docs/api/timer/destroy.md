# timer.destroy

Снимает именованный таймер этого плагина.

```lua
timer.destroy(name)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя, под которым он создан |

## Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если такой таймер был |
