# Именованные

Адресуются по имени, уникальному внутри плагина.

## timer.create {#create}

Заводит именованный таймер; повторный вызов заменяет старый.

```lua
timer.create(name, seconds, fn[, opts])
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | уникален внутри этого плагина |
| 2 | `seconds` | number | интервал, должен быть больше нуля |
| 3 | `fn` | function | обработчик |
| 4 | `opts` | table \| nil | см. [Опции](#create-опции) |

### Возвращает

Ничего.

### Опции {#create-опции}

| поле | тип |  |
|---|---|---|
| `once` | boolean | сработать один раз вместо повтора |
| `persist` | boolean | переживать смену карты; по умолчанию `true` |

### Пример

```lua
timer.create("ads.chat", 60, show_message)
```

Замена вместо добавления — это то, что нужно таймеру, который заводится в теле
плагина: `lua_reload <plugin>` выполнит эту строку второй раз и не оставит
второй таймер.

### Смотри также

- [timer.destroy](named.md#destroy)

## timer.destroy {#destroy}

Снимает именованный таймер этого плагина.

```lua
timer.destroy(name)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя, под которым он создан |

### Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если такой таймер был |
