# timer.cancel

Снимает таймер по id.

```lua
timer.cancel(id)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `id` | number | то, что вернул `after` или `every` |

## Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если таймер существовал и был снят |
