# export

Публикует функцию плагина наружу.

```lua
export(name, fn[, opts])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя функции |
| 2 | `fn` | function | что вызывать |
| 3 | `opts` | table \| nil | см. [Опции](#опции) |

## Возвращает

Ничего.

## Опции

| поле | тип |  |
|---|---|---|
| `version` | number | версия экспорта, по умолчанию `1` |
| `override` | boolean | разрешить перерегистрацию имени |
