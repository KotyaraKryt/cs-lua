# import

Возвращает прокси к экспортам плагина; жёсткая зависимость.

```lua
import(plugin)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `plugin` | string | id плагина — имя его папки |

## Возвращает

| тип |  |
|---|---|
| `table` | прокси к экспортам |

Бросает ошибку, если плагина нет: зависимость падает при загрузке, а не через час на `nil`-вызове.

> [!NOTE]
> Плагины грузятся по алфавиту, поэтому `import` на этапе загрузки
> видит только тех, кто отсортирован раньше. Если порядок неудобен,
> бери зависимость лениво — внутри обработчика — или через
> [`optional`](optional.md).
