# Ключ-значение

Key-value поверх SQLite в каталоге плагина.

## store.open {#open}

Открывает хранилище.

```lua
store.open(name)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя хранилища |

### Возвращает

| тип |  |
|---|---|
| `store` | объект хранилища |

Ключ — строка, значение — таблица, число, строка или `boolean`. Повторный вызов
с тем же именем в том же плагине возвращает тот же объект: два объекта над одним
файлом означали бы две очереди записи, и вторая затирала бы первую.

Файл ложится в [`plugin.data_dir()`](../plugin/index.md#data_dir).

## s:get {#get}

Читает значение по ключу.

```lua
s:get(key)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `key` | string | ключ |

### Возвращает

| тип |  |
|---|---|
| `any \| nil` | значение или `nil` |

Видит то, что положено через `set`, ещё до записи на диск.

## s:set {#set}

Кладёт значение в очередь записи.

```lua
s:set(key, value)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `key` | string | ключ |
| 2 | `value` | any | таблица, число, строка или boolean |

### Возвращает

| тип |  |
|---|---|
| `store` | сам объект, для цепочки |

## s:delete {#delete}

Удаляет ключ.

```lua
s:delete(key)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `key` | string | ключ |

### Возвращает

| тип |  |
|---|---|
| `store` | сам объект |

## s:keys {#keys}

Все ключи хранилища.

```lua
s:keys()
```

### Возвращает

| тип |  |
|---|---|
| `table` | отсортированный массив строк |

Учитывает то, что ещё лежит в очереди записи.

## s:all {#all}

Всё содержимое хранилища.

```lua
s:all()
```

### Возвращает

| тип |  |
|---|---|
| `table` | `{ [key] = value }` |

<Warning>
Читает всё в память — это для отчёта или миграции, не для кода
на таймере.
</Warning>

## s:flush {#flush}

Записывает очередь на диск одной транзакцией.

```lua
s:flush()
```

### Возвращает

| тип |  |
|---|---|
| `boolean` | `true` при успехе |
| `string` | причина при ошибке |

Вызывается сам на `map_change` и при выгрузке плагина. Явно нужен, только если
данные должны лечь на диск прямо сейчас.

Записи откладываются намеренно: вставка вне транзакции — отдельный коммит с
синхронизацией на диск, и делать так на каждый фраг нельзя.

## s:pending {#pending}

Сколько записей ждёт в очереди.

```lua
s:pending()
```

### Возвращает

| тип |  |
|---|---|
| `number` | количество |
