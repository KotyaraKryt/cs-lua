# s:get

Читает значение по ключу.

```lua
s:get(key)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `key` | string | ключ |

## Возвращает

| тип |  |
|---|---|
| `any \| nil` | значение или `nil` |

Видит то, что положено через `set`, ещё до записи на диск.
