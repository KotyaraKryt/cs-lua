# store.open

Открывает хранилище.

```lua
store.open(name)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя хранилища |

## Возвращает

| тип |  |
|---|---|
| `store` | объект хранилища |

Ключ — строка, значение — таблица, число, строка или `boolean`. Повторный вызов
с тем же именем в том же плагине возвращает тот же объект: два объекта над одним
файлом означали бы две очереди записи, и вторая затирала бы первую.

Файл ложится в [`plugin.data_dir()`](../plugin/data_dir.md).
