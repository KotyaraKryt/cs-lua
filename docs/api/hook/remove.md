# hook.remove

Удаляет обработчик события.

```lua
hook.remove(event, id)
```

### Аргументы
| # | Имя     | Тип      | Описание                  |
| - | ------- | -------- | ------------------------- |
| 1 | `event` | `string` | Имя события               |
| 2 | `id`    | `string` | Идентификатор обработчика |

### Возвращает
| Тип       | Описание                           |
| --------- | ---------------------------------- |
| `boolean` | `true`, если обработчик был удалён |

### Пример
```lua
hook.remove("player_spawn", "myplugin.armor")
```
Удаляет обработчик `myplugin.armor`, зарегистрированный для события
`player_spawn`.

Плагин может удалить только свои обработчики.
