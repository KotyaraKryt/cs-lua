# hook.remove

Снимает подписку по имени события и id.

```lua
hook.remove(event, id)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `event` | string | имя события |
| 2 | `id` | string | id, под которым подписывались |

## Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если обработчик был |

Снимает только собственный обработчик плагина: один плагин не может тихо отписать чужой.
