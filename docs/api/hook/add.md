# hook.add

Добавляет обработчик события.

```lua
hook.add(event, id, fn)
```

### Аргументы
| # | Имя     | Тип        | Описание                                            |
| - | ------- | ---------- | --------------------------------------------------- |
| 1 | `event` | `string`   | Имя события                                         |
| 2 | `id`    | `string`   | Уникальный идентификатор обработчика внутри плагина |
| 3 | `fn`    | `function` | Функция, которая получает объект события            |

### Возвращает
Ничего.

### Пример

```lua
hook.add("player_spawn", "myplugin.armor", function(e)
  e.player:armor(100)
end)
```

После регистрации обработчик будет вызываться при каждом `player_spawn`.

## Идентификатор обработчика

Пара `event` и `id` однозначно определяет обработчик внутри плагина.

Если зарегистрировать обработчик с той же парой `event` и `id`, предыдущий
обработчик будет заменён:

```lua
hook.add("player_spawn", "myplugin.armor", function(e)
  e.player:armor(50)
end)

hook.add("player_spawn", "myplugin.armor", function(e)
  e.player:armor(100)
end)
```

В результате будет использоваться только второй обработчик.

Это позволяет безопасно перезагружать плагин через `lua_reload`, не создавая
дубликаты обработчиков.

Одинаковый `id` можно использовать в разных плагинах:
```lua
-- plugin_a
hook.add("player_spawn", "init", function(e)
  -- ...
end)

-- plugin_b
hook.add("player_spawn", "init", function(e)
  -- ...
end)
```

У каждого плагина свои зарегистрированные обработчики.

## Порядок вызова

Обработчики вызываются в порядке загрузки плагинов.

Порядок загрузки можно изменить с помощью [`load_order.txt`](/guides/plugin-structure#порядок-загрузки).

## Отмена события

Некоторые события можно отменить с помощью `e:cancel()`:

```lua
hook.add("player_hurt", "myplugin.block", function(e)
  e:cancel()
end)
```

После вызова `e:cancel()` событие считается отменённым, а следующие обработчики
этого события не вызываются.

## Пользовательские события

Для пользовательских событий имя должно содержать точку:

```lua
hook.add("myplugin.player_ready", "welcome", function(e)
  print("Player is ready")
end)
```

Имена без точки зарезервированы для событий движка.

<Warning> Неизвестное имя события без точки вызывает ошибку. </Warning>
