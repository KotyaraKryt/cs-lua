# hook.run

Запускает пользовательское событие.

```lua
hook.run(event[, data])
```

### Аргументы
| # | Имя     | Тип            | Описание                          |
| - | ------- | -------------- | --------------------------------- |
| 1 | `event` | `string`       | Имя события, обязательно с точкой |
| 2 | `data`  | `table \| nil` | Данные события                    |

### Возвращает
| Тип     | Описание        |
| ------- | --------------- |
| `table` | Таблица события |

### Пример

Создадим пользовательское событие и передадим в него данные:

```lua
local e = hook.run("shop.buying", {
  player = p,
  item = item
})

if e.cancelled then
  return
end
```
`hook.run()` передаёт таблицу `data` зарегистрированным обработчикам и
возвращает ту же таблицу после их выполнения.

## Ограничения

Имя пользовательского события должно содержать точку. Это позволяет отличать
собственные события от событий, предоставляемых движком.

```lua
hook.run("shop.buying")
```

Движковые события нельзя запускать через `hook.run()`.
