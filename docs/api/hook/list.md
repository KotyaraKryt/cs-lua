# hook.list

Возвращает список зарегистрированных обработчиков.

```lua
hook.list([event])
```

### Аргументы
| # | Имя     | Тип             | Описание                                                  |
| - | ------- | --------------- | --------------------------------------------------------- |
| 1 | `event` | `string \| nil` | Если указано, возвращает обработчики только этого события |

### Возвращает
| Тип     | Описание                                                  |
| ------- | --------------------------------------------------------- |
| `table` | Массив объектов `{ event = ..., id = ..., plugin = ... }` |

### Пример

Получить все зарегистрированные обработчики:

```lua
local hooks = hook.list()

for _, entry in ipairs(hooks) do
  print(entry.event, entry.id, entry.plugin)
end
```
Можно указать событие, чтобы получить только его обработчики:

```lua
local hooks = hook.list("player_spawn")
```
