# hook.list

Возвращает список подписок в порядке вызова.

```lua
hook.list([event])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `event` | string \| nil | только по одному событию |

## Возвращает

| тип |  |
|---|---|
| `table` | массив `{ event = , id = , plugin = }` |

Консольная обёртка — [`lua_hooks`](../console.md).
