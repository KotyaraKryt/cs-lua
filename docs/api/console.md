# Консольные команды

Серверная консоль и rcon.

## Управление

| команда | |
|---|---|
| `lua_reload` | пересоздать Lua-состояние и перечитать все плагины |
| `lua_reload <plugin>` | перезагрузить один плагин, остальных не трогая |
| `lua_list` | плагины, счётчики хендлеров, таймеров и открытых баз |
| `lua_hooks [событие]` | кто на что подписан, в порядке вызова |
| `lua_exports` | кто что публикует через `export()` |
| `lua_precache` | занятые и свободные слоты прекеша |
| `lua_perms <что>` | `groups`, `list`, `users`, `who`, `check`, `grant`, `revoke`, `save`, `reload` |

`lua_reload <plugin>` снимает хендлеры, таймеры, команды и базы плагина,
выполняет [`plugin.on_unload`](plugin/on_unload.md) и запускает `init.lua`
заново с чистым кешем `require`.

> [!NOTE]
> После правок в `core/` и `include/` нужна полная перезагрузка: их разделяют
> все плагины.

## Диагностика вывода

| команда | |
|---|---|
| `lua_chat <текст>` | всем в чат, теги цвета работают |
| `lua_chat_as <id> <текст>` | то же от имени игрока: видно, как красит `{team}` |
| `lua_hud <текст>` | то же в HUD |
| `lua_dhud <текст>` | то же в DHUD |
| `lua_test_ru` | «Привет» в UTF-8 и CP1251 — какой вариант читается |
| `lua_debug` | id user messages, кеш игроков, 4 пробные строки в чат |

Вывод идёт всем подключённым — это способ увидеть сообщение глазами игрока.

## Cvar'ы модуля

| cvar | по умолчанию | |
|---|---|---|
| `cslua_cp1251` | `0` | конвертировать UTF-8 в CP1251 для старых клиентов |
| `cslua_db_timeout_ms` | `200` | дольше — запрос прерывается ошибкой; `0` снимает ограничение |
| `cslua_db_warn_ms` | `25` | дольше — предупреждение в консоль с именем плагина |
