# vec

Векторная математика: расстояние, длина, нормализация, углы.

Чистая математика без обращения к движку или сущностям — векторы теми же
тройками чисел, что и везде в модуле (`p:origin()` возвращает `x, y, z`,
а не таблицу, и `vec.*` принимает их так же).

## vec.distance {#distance}

Расстояние между двумя точками.

```lua
vec.distance(x1, y1, z1, x2, y2, z2)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x1, y1, z1` | number | первая точка |
| 2 | `x2, y2, z2` | number | вторая точка |

### Возвращает

| тип |  |
|---|---|
| `number` | расстояние в юнитах |

### Пример

```lua
local x1, y1, z1 = p:origin()
local x2, y2, z2 = other:origin()
local d = vec.distance(x1, y1, z1, x2, y2, z2)
```

<Note>
`p:origin()` — не последний аргумент вызова, поэтому Lua обрежет его до
одного значения, если передать его напрямую вторым в списке аргументов:
разложи обе точки в переменные, как в примере выше.
</Note>

Длина вектора.

vec.length(x, y, z)

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | вектор |

### Возвращает

| тип |  |
|---|---|
| `number` | длина |

## vec.normalize {#normalize}

Вектор единичной длины в том же направлении.

```lua
vec.normalize(x, y, z)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | вектор |

### Возвращает

| тип |  |
|---|---|
| `number, number, number` | единичный вектор |

Нулевой вектор нормализуется сам в себя — деления на ноль не будет.

## vec.to_angle {#to_angle}

Углы, которые смотрят вдоль вектора.

```lua
vec.to_angle(x, y, z)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `x, y, z` | number | вектор направления |

### Возвращает

| тип |  |
|---|---|
| `number, number, number` | `pitch, yaw, roll` |

### Пример

```lua
local px, py, pz = p:origin()
local pitch, yaw, roll = vec.to_angle(target.x - px, target.y - py, target.z - pz)
p:angles(pitch, yaw, roll)   -- модель игрока разворачивается на точку
```

Обратная операция для [vec.angle_vector](index.md#angle_vector).

## vec.angle_vector {#angle_vector}

Единичный вектор направления взгляда для заданных углов.

```lua
vec.angle_vector(pitch, yaw, roll)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `pitch, yaw, roll` | number | углы |

### Возвращает

| тип |  |
|---|---|
| `number, number, number` | единичный вектор вперёд |

### Пример

```lua
local fx, fy, fz = vec.angle_vector(p:pev("v_angle"))
```

Тот же движковый вызов, что `p:trace()` использует для направления взгляда
игрока (`MAKE_VECTORS`), только без привязки к конкретному игроку — годится
для сущностей и вычисленных углов.
