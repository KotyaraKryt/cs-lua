# st:query

Выполняет выражение и возвращает все строки.

```lua
st:query(...)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `...` | any | значения для `?` |

## Возвращает

| тип |  |
|---|---|
| `table` | массив строк |
