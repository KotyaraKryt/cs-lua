# st:first

Выполняет выражение и возвращает первую строку.

```lua
st:first(...)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `...` | any | значения для `?` |

## Возвращает

| тип |  |
|---|---|
| `table \| nil` | строка или `nil` |
