# db

SQLite: база — файл в каталоге плагина.

Вкомпилирован в модуль: сервера, драйвера и конфига нет. Нужен там, где данные
надо **запрашивать**; для конфига и списка админов проще
[`store`](../store/index.md).

Значения передаются через `?` и подставляются драйвером.

```lua
db:exec("INSERT INTO kills VALUES (?, ?, ?)", p:steamid(), weapon, os.time())
```

<Warning>
Не склеивай запрос из данных игрока. Ник — это то, что игрок написал сам:
через `?` он попадёт в базу строкой, чем бы ни был, в склейке — станет частью
запроса.
</Warning>

## Типы

| Lua | SQLite |
|---|---|
| `nil` | `NULL` |
| `true`, `false` | `1`, `0` — булева типа в SQLite нет |
| целое число | `INTEGER` |
| дробное | `REAL` |
| строка | `TEXT` с длиной: двоичные данные проходят целиком |

Обратно `INTEGER` и `REAL` приходят числом, `TEXT` и `BLOB` — строкой. `NULL`
приходит как `nil`, то есть ключа в таблице строки просто нет.

Числа в Lua — double: точность целых кончается на 2^53.

## Запросы идут в кадре

Модуль однопоточный, запрос выполняется прямо в игровом кадре. Локальный файл в
WAL отвечает за доли миллисекунды, но запрос по таблице без индекса заморозит
сервер целиком, поэтому слишком долгий прерывается:

```
query aborted after 203ms (cslua_db_timeout_ms is 200).
Add an index, narrow the query, or raise the limit
```

| cvar | по умолчанию | |
|---|---|---|
| `cslua_db_timeout_ms` | `200` | дольше — прерывание ошибкой; `0` снимает ограничение |
| `cslua_db_warn_ms` | `25` | дольше — предупреждение с именем плагина |

Увидел предупреждение — ставь индекс, а не поднимай лимит. Сторож не покрывает
ожидание блокировки: если файл базы держит другой процесс, ждать придётся честно.
