# Подготовленное выражение

## st:run {#stmt_run}

Выполняет выражение, ничего не возвращающее.

```lua
st:run(...)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `...` | any | значения для `?` |

### Возвращает

| тип |  |
|---|---|
| `number` | сколько строк изменено |

## st:query {#stmt_query}

Выполняет выражение и возвращает все строки.

```lua
st:query(...)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `...` | any | значения для `?` |

### Возвращает

| тип |  |
|---|---|
| `table` | массив строк |

## st:first {#stmt_first}

Выполняет выражение и возвращает первую строку.

```lua
st:first(...)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `...` | any | значения для `?` |

### Возвращает

| тип |  |
|---|---|
| `table \| nil` | строка или `nil` |

## st:sql {#stmt_sql}

Исходный текст запроса.

```lua
st:sql()
```

### Возвращает

| тип |  |
|---|---|
| `string` | SQL |

## st:close {#stmt_close}

Освобождает выражение.

```lua
st:close()
```

### Возвращает

Ничего.
