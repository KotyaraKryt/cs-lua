# db:query

Выполняет запрос и возвращает все строки.

```lua
db:query(sql, ...)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `sql` | string | SQL |
| 2 | `...` | any | значения для `?` |

## Возвращает

| тип |  |
|---|---|
| `table` | массив строк; пустой, если ничего не нашлось |

Строка — таблица с ключами по именам колонок.
