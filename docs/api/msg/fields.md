# Поля сообщения

Каждая функция описывает одно поле в порядке провода — сама ничего не
отправляет, только проверяет диапазон и возвращает значение, которое
`msg.send` пишет по очереди.

```lua
msg.send("one", "TextMsg", e.player,
  msg.byte(4), msg.string("hello"))
```

## msg.byte {#byte}

n — `0..255` (`WRITE_BYTE` в SDK).

```lua
msg.byte(n)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `n` | number \| string | `0..255` |

### Возвращает

| тип |  |
|---|---|
| `table` | значение для `msg.send` — передавай как есть, не пересобирай руками |

<Warning>
Значение вне диапазона — ошибка Lua сразу в момент вызова `msg.byte`/
`msg.short`/..., до `msg.send`. Так проще найти, какое именно поле не влезло.
</Warning>

## msg.entity {#entity}

v — игрок или объект `ents`, индекс `>= 1` (`WRITE_ENTITY` в SDK).

```lua
msg.entity(v)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `v` | number \| string | игрок или объект `ents`, индекс `>= 1` |

### Возвращает

| тип |  |
|---|---|
| `table` | значение для `msg.send` — передавай как есть, не пересобирай руками |

Принимает и игрока (`e.player`), и сущность из `ents` — что угодно с полем `id` (игрок) или `index` (сущность). `0` (мир) не годится.
