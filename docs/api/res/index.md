# res

Прекеш ресурсов карты.

Ресурсы объявляются один раз в теле плагина — модуль проигрывает список на
каждой карте сам, поэтому таймингов прекеша здесь нет.

|  |  |
|---|---|
| [`res.sound`](sound.md) | Регистрирует звук для прекеша |
| [`res.model`](model.md) | Регистрирует модель для прекеша |
