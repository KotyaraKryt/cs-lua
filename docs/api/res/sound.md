# res.sound

Регистрирует звук для прекеша.

```lua
res.sound(path)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `path` | string | путь от `cstrike/sound/` |

## Возвращает

Ничего.

## Пример

```lua
res.sound("items/9mmclip1.wav")
```

## Лимит 512 слотов

У GoldSrc жёсткий предел: 512 слотов на звуки и 512 на модели. Переполнение не
возвращает ошибку — движок падает с `Host_Error`, и сервер умирает.

Модуль считает занятые слоты и отказывает **до** переполнения: ресурс не
прекешится, плагин-виновник отключается, его хендлеры и таймеры снимаются, в
`lua_list` он помечается `[FAILED]`. Сервер продолжает работать.

Запас смотрится через [`lua_precache`](../console.md).

> [!WARNING]
> Движок принимает прекеш только в момент загрузки карты, поэтому
> вызов идёт в теле плагина, а не в обработчике. Вызов при уже
> загруженной карте запоминает ресурс и вводит его со следующей.
