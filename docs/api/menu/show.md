# m:show

Показывает меню игроку.

```lua
m:show(p[, page])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `p` | player | кому показать |
| 2 | `page` | number \| nil | страница с нуля; по умолчанию первая |

## Возвращает

Ничего.
