# m:color

Перекрашивает меню целиком.

```lua
m:color(spec)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `spec` | string \| table | тот же формат, что `opts.color` |

## Возвращает

| тип |  |
|---|---|
| `menu` | сам объект, для цепочки |

Работает до `m:show()`.
