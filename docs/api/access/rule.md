# access.rule

Задаёт динамическое правило для ноды.

```lua
access.rule(node, fn)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `node` | string | нода |
| 2 | `fn` | function | получает `(p, ctx)`, возвращает boolean |

## Возвращает

Ничего.

## Пример

```lua
access.rule("shop.buy", function(p, ctx)
	return p:playtime() > 3600
end)
```

Для случаев, когда правом управляет логика, а не таблица.

> [!NOTE]
> Правило вызывается **только если ноду не покрыл никто**. Явный
> `deny` в файлах всегда сильнее.
