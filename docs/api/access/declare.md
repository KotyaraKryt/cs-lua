# access.declare

Объявляет ноду прав.

```lua
access.declare(node[, opts])
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `node` | string | конкретная нода, без звёздочек |
| 2 | `opts` | table \| nil | см. [Опции](#опции) |

## Возвращает

Ничего.

## Опции

| поле | тип |  |
|---|---|---|
| `desc` | string | описание для `lua_perms list` |
| `default` | string \| boolean | группа, которой нода выдана по умолчанию; `true` — всем |

## Пример

```lua
access.declare("shop.vip.buy", { desc = "Покупка в VIP-магазине", default = "vip" })
```

Объявление необязательно, но даёт две вещи: нода попадает в `lua_perms list`, а
опечатка в `p:can("shop.vip.by")` выводит предупреждение в консоль вместо тихого
отказа.

`default` действует с самым низким приоритетом: любой `deny` в файлах забирает
ноду обратно.
