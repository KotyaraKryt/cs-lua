# cmd

`cmd` позволяет создавать команды для чата, консоли и серверной консоли.

Команда получает объект `ctx`, через который можно узнать источник вызова,
игрока, аргументы и отправить ответ.

```lua
cmd.add("hello", function(ctx)
  ctx.reply("Hello!")
end)
```
Одна регистрация может обслуживать несколько источников. При необходимости источник можно ограничить через опцию `source`.

# Методы
|                           |                                           |
| ------------------------- | ----------------------------------------- |
| [`cmd.add`](add.md)       | Зарегистрировать команду                  |
| [`cmd.remove`](remove.md) | Удалить зарегистрированную команду        |
| [`cmd.list`](list.md)     | Получить список зарегистрированных команд |
