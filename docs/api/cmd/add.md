# cmd.add

Регистрирует команду.

```lua
cmd.add(name, fn[, opts])
```

### Аргументы
| # | Имя    | Тип            | Описание                           |
| - | ------ | -------------- | ---------------------------------- |
| 1 | `name` | `string`       | Имя команды без префикса           |
| 2 | `fn`   | `function`     | Обработчик команды, получает `ctx` |
| 3 | `opts` | `table \| nil` | Дополнительные параметры команды   |

### Возвращает
Ничего

### Опции

| Поле | Тип | Описание |
|---|---|---|
| `source` | `string \| table` | Источник команды: `console`, `chat`, `chat_team`. Если не указать, команда доступна из всех источников |
| `perm` | `string` | Нода права, которая проверяется перед вызовом обработчика |
| `target` | `number` | Номер аргумента с именем игрока. Найденный игрок доступен через `ctx.target` |
| `immunity` | `boolean` | `false` отключает проверку иммунитета при использовании `target` |

### Пример

Создадим команду `heal`, которая восстанавливает игроку 25 единиц здоровья:

```lua
cmd.add("heal", function(ctx)
  local p = ctx.player

  if p then
    p:health(p:health() + 25)
  end

  ctx.reply("healed")
end)
```
Команда доступна из всех источников, поскольку `source` не указан.

## Источник команды

С помощью `source` можно ограничить, откуда разрешено вызывать команду.

```lua
cmd.add("kick", fn, { source = "console" })
```
Такая команда доступна только из серверной консоли.

Для чата можно использовать:
```lua
cmd.add("hello", fn, { source = "chat" })
```

А для команд, введённых только в командном чате:
```lua
cmd.add("plant", fn, { source = "chat_team" })
```

Можно также указать несколько источников:
```lua
cmd.add("hello", fn, {
  source = { "chat", "console" }
})
```

Если `source` не указан, команда доступна из всех поддерживаемых источников.

## Права доступа

С помощью `perm` можно ограничить выполнение команды правом:

```lua
cmd.add("slay", function(ctx)
  -- ...
end, {
  perm = "admin.slay"
})
```
Право проверяется до вызова обработчика. Если у вызывающего нет указанной ноды,
обработчик не будет выполнен.

## Целевой игрок

Опция `target` указывает номер аргумента команды, в котором ожидается имя игрока.

```lua
cmd.add("slay", function(ctx)
  local target = ctx.target

  if target then
    target:kill()
  end
end, {
  target = 1
})
```
`cs-lua` самостоятельно находит игрока по слоту, `#userid` или части ника.
Найденный игрок доступен через `ctx.target`.

## Иммунитет

При использовании `target` `cs-lua` проверяет иммунитет целевого игрока.

Чтобы отключить эту проверку, передайте `immunity = false`:

```lua
cmd.add("slay", function(ctx)
  if ctx.target then
    ctx.target:kill()
  end
end, {
  target = 1,
  immunity = false
})
```
По умолчанию проверка иммунитета включена.

## Контекст команды

Обработчик команды получает `ctx` — объект с информацией о текущем вызове:

```lua
cmd.add("hello", function(ctx)
  print(ctx.name)
end)
```

### Поля
| Поле              | Тип             | Описание                                           |
| ----------------- | --------------- | -------------------------------------------------- |
| `ctx.player`      | `player \| nil` | Игрок, вызвавший команду. `nil` для консоли и RCON |
| `ctx.args`        | `table`         | Аргументы после имени команды                      |
| `ctx.name`        | `string`        | Имя команды                                        |
| `ctx.source`      | `string`        | Источник: `console`, `chat` или `chat_team`        |
| `ctx.reply(text)` | `function`      | Отправляет ответ туда, откуда была вызвана команда |
| `ctx.target`      | `player`        | Целевой игрок, найденный через `opts.target`       |
| `ctx.can(node)`   | `function`      | Проверяет право вызывающего                        |
