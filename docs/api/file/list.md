# file.list

Возвращает имена всех файлов верхнего уровня в каталоге плагина.

```lua
file.list()
```

### Аргументы
Нет.

### Возвращает
Массив имён файлов (`{ string, ... }`). Если каталога плагина ещё нет —
пустой массив `{}`, не ошибка.

### Пример

```lua
for _, name in ipairs(file.list()) do
  print(name)
end
```

<Warning>
Подпапка `logs/`, которую создаёт [`log.write`](../log/index.md), в список не
попадает — это отдельное хранилище, не файлы плагина.
</Warning>
