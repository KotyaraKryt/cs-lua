# file.write

Записывает содержимое в файл, полностью заменяя то, что там было (или
создавая файл, если его не было).

```lua
file.write(name, content)
```

### Аргументы
| # | Имя       | Тип      | Описание                                |
| - | --------- | -------- | ---------------------------------------- |
| 1 | `name`    | `string` | Имя файла в каталоге плагина (см. [`file`](index.md)) |
| 2 | `content` | `string` | Что записать, до 4 МиБ                   |

### Возвращает
`true` при успехе. При ошибке — `nil` и вторым значением причина.

### Пример

```lua
local ok, err = file.write("report.csv", "name,score\n")
if not ok then
  print("не смог записать: " .. err)
end
```

Для дозаписи в конец существующего файла — [`file.append`](append.md).
