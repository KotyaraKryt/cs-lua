# file.remove

Удаляет файл из каталога плагина.

```lua
file.remove(name)
```

### Аргументы
| # | Имя    | Тип      | Описание                                |
| - | ------ | -------- | ---------------------------------------- |
| 1 | `name` | `string` | Имя файла (см. [`file`](index.md))       |

### Возвращает
`true` при успехе. При ошибке (в том числе если файла и не было) — `nil` и
вторым значением причина.

### Пример

```lua
local ok, err = file.remove("tmp.csv")
```
