# file.size

Возвращает размер файла в байтах.

```lua
file.size(name)
```

### Аргументы
| # | Имя    | Тип      | Описание                                |
| - | ------ | -------- | ---------------------------------------- |
| 1 | `name` | `string` | Имя файла (см. [`file`](index.md))       |

### Возвращает
Размер файла (`number`) при успехе.

Если файла нет (или имя не годится, или нет каталога плагина) — просто `nil`,
без второго значения: отсутствие файла здесь не ошибка, в отличие от
[`file.read`](read.md).

### Пример

```lua
local size = file.size("report.csv")
if size and size > 1024 * 1024 then
  file.remove("report.csv")
end
```
