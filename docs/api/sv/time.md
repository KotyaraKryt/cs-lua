# sv.time

Серверные часы в секундах.

```lua
sv.time()
```

## Возвращает

| тип |  |
|---|---|
| `number` | секунды с дробной частью |

Те же часы, на которых идут [таймеры](../timer/index.md). Обнуляются при смене карты.

> [!NOTE]
> `os.clock()` — это CPU-время, оно сильно расходится на сервере,
> который спит между кадрами. Для интервалов бери `sv.time()`.
