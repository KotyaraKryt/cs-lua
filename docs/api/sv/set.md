# c:set

Записывает значение переменной.

```lua
c:set(value)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | string \| number | новое значение |

## Возвращает

Ничего.

## Пример

```lua
sv.cvar("mp_friendlyfire"):set(1)
```
