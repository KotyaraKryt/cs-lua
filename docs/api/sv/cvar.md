# sv.cvar

Возвращает объект существующей переменной движка.

```lua
sv.cvar(name)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя переменной |

## Возвращает

| тип |  |
|---|---|
| `cvar \| nil` | `nil`, если такой переменной нет |

## Пример

```lua
local ft = sv.cvar("mp_freezetime")
if ft then print(ft:int()) end
```
