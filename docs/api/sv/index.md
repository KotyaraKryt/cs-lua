# sv

Сервер: часы, карта, консоль, переменные движка.

## Константы

| поле | тип | |
|---|---|---|
| `sv.version` | string | версия модуля, `"2.0.0"` |
| `sv.api` | number | версия Lua-API |
| `sv.dir` | string | абсолютный путь `addons/lua` |

## Сервер

|  |  |
|---|---|
| [`sv.time`](time.md) | Серверные часы в секундах |
| [`sv.map`](map.md) | Имя текущей карты |
| [`sv.cmd`](cmd.md) | Ставит команду в очередь серверной консоли |

## Cvar

|  |  |
|---|---|
| [`sv.cvar`](cvar.md) | Возвращает объект существующей переменной движка |
| [`sv.cvar_register`](cvar_register.md) | Заводит свою переменную движка |
| [`c:int`](int.md) | Значение переменной как целое |
| [`c:float`](float.md) | Значение переменной как число |
| [`c:str`](str.md) | Значение переменной как строка |
| [`c:set`](set.md) | Записывает значение переменной |
| [`c:name`](name.md) | Имя переменной |
