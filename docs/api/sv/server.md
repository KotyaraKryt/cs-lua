# Сервер

## sv.time {#time}

Серверные часы в секундах.

```lua
sv.time()
```

### Возвращает

| тип |  |
|---|---|
| `number` | секунды с дробной частью |

Те же часы, на которых идут [таймеры](../timer/index.md). Обнуляются при смене карты.

<Note>
`os.clock()` — это CPU-время, оно сильно расходится на сервере,
который спит между кадрами. Для интервалов бери `sv.time()`.
</Note>

## sv.map {#map}

Имя текущей карты.

```lua
sv.map()
```

### Возвращает

| тип |  |
|---|---|
| `string` | `"de_dust2"` |

## sv.maps {#maps}

Список карт, установленных на сервере.

```lua
sv.maps()
```

### Возвращает

| тип |  |
|---|---|
| `table` | имена без `.bsp`, порядок не гарантирован |

Читает `maps/` на диске напрямую, а не берёт список
откуда-то из движка — плагину меню голосования этого достаточно, чтобы
отсеять карты, которых на самом деле нет.

## sv.map_exists {#map_exists}

Есть ли карта на диске.

```lua
sv.map_exists(name)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `name` | string | имя без `.bsp` |

### Возвращает

| тип |  |
|---|---|
| `boolean` | `true`, если `maps/<name>.bsp` существует |

Дешевле, чем звать `sv.maps()` и искать в нём —
одна проверка файла вместо чтения всей папки.

## sv.cmd {#cmd}

Ставит команду в очередь серверной консоли.

```lua
sv.cmd(fmt, ...)
```

### Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `fmt` | string | команда или формат для `string.format` |
| 2 | `...` | any | подстановки |

### Возвращает

Ничего.

### Пример

```lua
sv.cmd("changelevel %s", next_map)
```

С одним аргументом строка уходит как есть — одинокий `%` в нике не превратится в директиву формата.

<Warning>
Длиннее 250 символов — ошибка: обрезанная команда выполнилась бы
как совсем другая.
</Warning>
