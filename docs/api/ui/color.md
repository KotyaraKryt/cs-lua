# ui.color

Разбирает цвет в `{ r, g, b }`.

```lua
ui.color(value)
```

## Аргументы

| # | имя | тип |  |
|---|---|---|---|
| 1 | `value` | string \| table | имя из палитры, `"#rrggbb"` или `{ r, g, b }` |

## Возвращает

| тип |  |
|---|---|
| `table` | `{ r, g, b }` |

## Пример

```lua
local rgb = ui.color("orange")     --> { 255, 160, 0 }
ui.color("#ffa000")
ui.color({ 255, 160, 0 })
```

Нужен, когда цвет вычисляется, а не пишется руками. В поля `color` значение
можно передавать и без разбора — их читает сам модуль.

## Палитра

`ui.palette` — таблица `имя → { r, g, b }`.

| имя | |
|---|---|
| `white`, `black`, `grey` | `gray` — синоним `grey` |
| `red`, `green`, `blue` | |
| `yellow`, `orange` | |

> [!WARNING]
> Неизвестное значение — ошибка со списком известных имён, а не
> тихий чёрный цвет.
