# Порядок загрузки плагинов.
#
# Обработчики событий вызываются в том порядке, в котором загрузились плагины.
# Обычно это неважно, но на отменяемом событии — player_hurt, player_chat,
# client_connect — решает, кто выиграет: e:cancel() обрывает цепочку.
#
# Здесь перечисляются плагины, которым нужно место в очереди. Они грузятся
# первыми и ровно в этом порядке. Всё, чего в файле нет, идёт после них по
# алфавиту, поэтому список не обязан быть полным.
#
# Одно имя в строке — имя папки плагина или файла без .lua. Пустые строки и
# всё после # игнорируются.
#
# Порядком распоряжается владелец сервера, а не автор плагина: это одно место,
# по которому видно, что на самом деле происходит.
#
# Пример: гасим урон раньше, чем его считают и масштабируют.
#
#   godmode
#   damager
#   stats
